# OfferClaw 隐私政策

最后更新：2026-09-09

OfferClaw 是一个运行在你自己浏览器里的开源求职辅助扩展。本页说明它收集什么、往哪里发送什么。

## 数据存储在哪里

**一切数据都只保存在你本机的浏览器扩展存储（`chrome.storage.local`）里：**

- 简历文本与求职画像（含领域、目标岗位、技能、证书等）
- LLM 配置（服务商、Base URL、API Key、模型）
- 投递看板里的岗位记录
- 面板的位置与折叠状态（保存在招聘站点页面自己的 localStorage，只含位置数值）

没有云端同步，没有遥测，没有统计上报，开发者无法接触到你的任何数据。

## 数据会发往哪里

**只会发往你自己配置的 LLM 服务商**（如硅基流动、智谱、DeepSeek、OpenAI 等）：

- 打分 / 批量扫描 / 生成打招呼语时，你的简历内容（或其压缩摘要）与岗位 JD 文本会作为提示词发送给你配置的服务商接口
- 请求头带上你本机保存的 API Key
- 除此之外，OfferClaw 不向任何服务器发送数据

请同时阅读你所选服务商自己的隐私政策——数据一旦离开本机，就受该服务商政策约束。

## 权限说明

- **`storage`**：保存画像、配置与看板记录。
- **`activeTab` + `scripting`**：只在九个已适配招聘站之外，你在看板里主动点「在本页启用」时，向当前页注入一次面板脚本。不点击就不会接触任何非招聘站页面。
- **主机权限（BOSS 直聘 / 实习僧 / 51job / 智联招聘 / 牛客网 / 应届生求职网 / LinkedIn / Greenhouse / Lever）**：用于在这几类站点上注入悬浮面板、读取当前页岗位信息。**扫描时的详情页抓取只在你本人已登录的会话内进行**，用于补全岗位描述以打分，不绕过任何反爬措施，不批量爬取，不存储站点数据。
- **`optional_host_permissions`（https://*/*）**：当你保存自定义 LLM Base URL 时，按单个域名（如 `https://api.example.com/*`）向你在浏览器里申请授权，绝不会被用于访问招聘网站。
- Base URL 只允许 `https`（本机 `localhost` / `127.0.0.1` 例外），防止 API Key 明文外发。

## 不会做的事

- 不自动投递、不自动填表、不群发消息——投递永远由你手动完成
- 不把简历或 API Key 发给除你配置的服务商之外的任何一方
- 不在页面上展示你的 API Key（面板与看板只能得知“是否已配置”这一个布尔值）
- 不采集浏览历史，不上报崩溃与使用统计

## 删除数据

在扩展的选项页清空各字段、在系统里卸载扩展，或直接在 `chrome://extensions` 移除扩展，即可删除全部本机数据。
